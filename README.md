# 東北春日旅の栞 · 2027

日本東北自由行，2027/04/19–04/28。以使用者提供的《2027 日本東北旅遊行程討論版 v4 含狐狸村》為來源，採富士藍、雪白與櫻花粉的日式圓角設計。

## 每日行程

仙台 → 弘前 → 高山稻荷神社 → 青森、奧入瀨 → 盛岡 → 一關 → 仙台往返白石、岩沼 → SDJ。狐狸村 4/27；金蛇水神社 4/28。中尊寺、松島維持選配，不自動排入。飯店名稱、訂單、航班號、未公布班次保持待確認。所有地面時間均為討論估算，非已訂車次。

## 功能

- 行程／指南／天氣三個底部浮動分頁與每日切換。
- 六種景點分類，必吃、必買、必拍標籤，官方資訊、拍照 tips、Google Maps、依景點自動產生停車與加油搜尋。
- 每一站可上傳旅記照片，以 IndexedDB 留在本機；圖片先縮圖，支援含照片 JSON 備份。
- 隨身背包、手提行李、托運行李、日本購物清單，可新增、刪除、編輯與調整數量。
- 雲端文件連結、航班、住宿區域、租車憑證欄位、備忘錄、匯率與手動試算表同步。
- 東北活動、溫泉散策、美食補充為候選，不擅自新增到行程。
- 旅行日與近期天氣分開。Open-Meteo 最遠約 16 日，超出範圍不填數字；降雪機率未提供時明示，不以降水機率替代；雪深為模式值。
- PWA、此 app 範圍內的離線快取，沒有修改名古屋 app。

## 資料與更新

保留 `tohoku-2027-0419:v1:data` 儲存鍵，遷移舊版購物、備忘、住宿與預約。v4 只填入尚無自訂行程的日期，不覆蓋已新增的個人行程。新版照片存在獨立的 `tohoku-2027-travel-photos` IndexedDB。資料不會自動跨裝置同步，請先匯出含照片備份再換機。

GitHub Pages：main 分支、根目錄。來源資料與聯絡資訊查核日 2026/10/23，出發前依 2027 官方公告再次確認。
